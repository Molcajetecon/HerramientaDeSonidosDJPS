Control de Sonidos

Versión 1.0 - Aplicación Web para Reproducir Sonidos Interactivos

1. Introducción

La aplicación Control de Sonidos es una herramienta web interactiva que permite reproducir una variedad de sonidos predefinidos mediante botones en pantalla. Está diseñada para ser utilizada en navegadores web modernos y ofrece funcionalidades como configuración personalizada, carga de archivos de audio personalizados y almacenamiento local de configuraciones.

Características principales:
  • 9 botones de sonido con presets predefinidos (risa, bocina, aplausos, etc.).
  • Configuración personalizable de etiquetas y sonidos.
  • Soporte para carga de archivos de audio personalizados (MP3, WAV, etc.).
  • Interfaz responsiva y moderna con diseño oscuro.
  • Almacenamiento automático de configuraciones en el navegador.

2. Requisitos del Sistema

  • Navegador Web: Chrome, Firefox, Safari o Edge (versión reciente recomendada).
  • Permisos: La aplicación requiere acceso al audio del navegador. Asegúrese de permitir el audio cuando se le solicite.
  • Conexión a Internet: Necesaria para cargar las librerías externas (Tone.js y Tailwind CSS). Una vez cargada, puede funcionar sin conexión.
  • Almacenamiento Local: Utiliza localStorage del navegador para guardar configuraciones. No se requieren permisos adicionales.

3. Cómo Usar la Aplicación

3.1. Abrir la Aplicación

Abra el archivo sonidos.html en su navegador web. La página se cargará automáticamente y mostrará la interfaz principal con los botones de sonido.

3.2. Reproducir Sonidos

Haga clic en cualquiera de los botones de sonido en la cuadrícula principal. Cada botón reproducirá el sonido asignado. Los sonidos incluyen:

  • Risa 'Mala'
  • Bocina Fuerte
  • Aplausos (Clap)
  • Error (Fail)
  • Timbre de Puerta
  • ¡Sorpresa!
  • Ding (Acertado)
  • Whoosh (Pase rápido)
  • Archivo Personalizado (si se configura)
Nota: Al hacer clic por primera vez, el navegador puede solicitar permiso para reproducir audio. Acepte para habilitar el sonido.

3.3. Mensajes de Estado

En la parte inferior de la pantalla aparecerán mensajes temporales indicando el estado de las acciones, como "Sistema de Audio Iniciado" o "Reproduciendo: [Nombre del Sonido]".

4. Configuración de la Aplicación

4.1. Abrir el Modal de Configuración

Haga clic en el botón "⚙️ Configurar Sonidos" en la parte superior de la página. Se abrirá un modal con opciones de configuración para cada botón.

4.2. Personalizar Etiquetas

Para cada botón, puede cambiar la etiqueta (nombre) en el campo de texto correspondiente. Esto cambiará el texto que aparece en el botón.

4.3. Seleccionar Sonidos Predefinidos

Use el menú desplegable para seleccionar un sonido predefinido diferente para cada botón. Los presets disponibles se listan en la sección 3.2.

4.4. Cargar Archivos de Audio Personalizados

Seleccione "Archivo Personalizado" en el menú desplegable de un botón. Aparecerá un campo para cargar un archivo de audio.

  1. Haga clic en "Seleccionar archivo" y elija un archivo de audio (MP3, WAV, etc.) de su dispositivo.
  2. El archivo se cargará automáticamente. Aparecerá un mensaje confirmando la carga.
  3. Límite de tamaño: 5 MB por archivo. Archivos más grandes pueden no guardarse correctamente.
Importante: Los archivos personalizados se almacenan en el navegador. Si borra el caché o cambia de navegador, se perderán. Guarde copias de seguridad de sus archivos originales.

4.5. Guardar Configuración

Después de realizar cambios, haga clic en "Guardar Configuración". Los cambios se aplicarán inmediatamente y se guardarán en el navegador para futuras sesiones.

Si no guarda, los cambios se perderán al cerrar el modal o recargar la página.

4.6. Cerrar Configuración

Haga clic en "Cerrar" para salir del modal sin guardar cambios, o use "Guardar Configuración" para aplicar y cerrar.

5. Solución de Problemas

  • No se reproduce sonido: Verifique que el navegador tenga permisos de audio habilitados. Intente hacer clic en cualquier parte de la página para activar el audio.
  • Archivo personalizado no se carga: Asegúrese de que el archivo sea un formato de audio válido (MP3, WAV, etc.) y no exceda 5 MB.
  • Configuración no se guarda: Verifique que localStorage esté habilitado en su navegador. En modo incógnito, los datos pueden no persistir.
  • Página no carga correctamente: Asegúrese de tener conexión a internet para cargar las librerías externas. Si persiste, intente recargar la página.
  • Errores en consola: Abra las herramientas de desarrollador del navegador (F12) y revise la consola para mensajes de error detallados.

6. Consejos y Mejores Prácticas

  • Experimente con diferentes combinaciones de sonidos para crear efectos personalizados.
  • Use archivos de audio cortos (menos de 1 MB) para un mejor rendimiento.
  • Guarde su configuración regularmente para evitar perder cambios.
  • La aplicación es responsiva y funciona en dispositivos móviles, pero el audio puede requerir interacción táctil inicial.

7. Información Técnica

Esta aplicación utiliza:

  • Tone.js: Librería para síntesis y reproducción de audio.
  • Tailwind CSS: Framework para estilos responsivos.
  • localStorage: Para almacenamiento local de configuraciones.
  • FileReader API: Para cargar archivos de audio personalizados.
